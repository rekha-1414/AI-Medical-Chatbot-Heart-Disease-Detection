# ❤️ AI Medical Chatbot for Heart Disease Detection

## Overview

AI Medical Chatbot for Heart Disease Detection is a Streamlit-based web application that allows users to upload ECG images and receive heart disease predictions along with medical explanations and health recommendations.

## Features

* ECG Image Upload
* Heart Disease Prediction
* Confidence Score Display
* Medical Explanation
* Health Recommendations
* Interactive Chatbot

## Technologies Used

* Python
* Streamlit
* Pillow

## Installation

```bash
pip install -r requirements.txt
```

```bash
streamlit run app.py
```

## Project Workflow

Upload ECG Image
↓
Analyze ECG
↓
Heart Disease Prediction
↓
Medical Explanation
↓
Health Recommendations
